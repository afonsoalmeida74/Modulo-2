Introdução ao CSS

CSS permite controlar a apresentação visual de documentos HTML.

Como funciona

Uma regra CSS é composta por um seletor e por um bloco de declarações. Cada declaração contém uma propriedade e um valor.

p {
  color: #334155;
  line-height: 1.6;
}
