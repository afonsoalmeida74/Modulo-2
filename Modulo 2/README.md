## Descrição e decisões
- **EX01:** demonstra seletores de elemento, classe, ID, descendentes, atributos e pseudo-classes, incluindo `hover` e `focus-visible`.
- **EX02:** compara `content-box` e `border-box`, mostrando o efeito de `width`, `padding`, `border` e `margin`.
- **EX03:** cria uma página de documentação com hierarquia tipográfica e variáveis CSS.
- **EX04:** apresenta componentes reutilizáveis: cartões, botões, alertas, badges e formulário.
- **EX05:** demonstra cinco layouts Flexbox com direção, alinhamento, quebra de linha, espaçamento, crescimento e redução.
- **EX06:** implementa uma barra de navegação com Flexbox e adaptação a ecrãs pequenos.
- **EX07:** cria uma galeria responsiva com CSS Grid, `gap`, imagens flexíveis e áreas com tamanhos diferentes.
- **EX08:** constrói um dashboard com Grid para header, sidebar, conteúdo principal e footer, incluindo cartões e tabela.
- **EX09:** desenvolve uma landing page Mobile First com breakpoints para diferentes larguras e alternância de modo escuro.

## Como executar
Abre o ficheiro `index.html` de cada pasta num navegador. O EX07 utiliza imagens remotas, pelo que necessita de ligação à Internet.

Antes de entregar, substitui os campos entre parênteses retos pelos teus dados e confirma que compreendes o funcionamento de cada regra CSS.
